# Changelog

## 1.1 - 2026-10-14
- Larger, sharper menu, list and playback text (smooth outline font instead of an enlarged pixel font).
- New playback layout: album art starts at the top, clock sits above the peak meters, battery above the level fader.
- Peak meters and volume fader are much taller (volume fader about 1.8x longer, so small movements change the volume less).
- Checked in the Rockbox simulator, including Japanese (CJK) text.
