# Oddlogic Rockbox Themes

Themes for the [Rockbox](https://www.rockbox.org) firmware, made for the HiBy R1 (480x800, touchscreen).

| Theme | Version | CJK | Look |
|-------|---------|-----|------|
| [Drift Mountain](themes/drift-mountain) | 1.1 | ✅ | Car head-unit playback screen, tile main menu, list menus |
| [In Love](themes/in-love) | 1.1 | ✅ | Soft pink-on-plum player with dashed outlines, rounded buttons and a framed album-art card |
| [Pretty Sad](themes/pretty-sad) | 1.1 | ✅ | A taped polaroid-style album card on a dark blue-green background with coral accents |
| [Waveform Bot HUD](themes/waveform-bot-hud) | 1.1 | ✅ | A navy and gold sci-fi HUD with VU meters either side of the album art |
| [Teal Vocaldroid](themes/teal-vocaldroid) | 1.1 | ✅ | A teal and pink digital-audio player with level meters beside the album art |
| [Studio Console](themes/studio-console) | 1.0 | ✅ | A vintage recording-studio console with green glowing tiles, peak meters and a touch volume fader |

All themes include fonts with Japanese, Chinese and Korean (CJK) glyphs, so CJK track titles, artists and file names display correctly.

## Found a bug or want the latest version?

- **Report a bug:** [open an issue](../../issues/new/choose). Please include your device, Rockbox version and a photo or screenshot.
- **Download:** each theme folder has a `download/` zip, and the [Releases](../../releases) page lists new versions and what changed.
- Each theme has its own `CHANGELOG.md` in its folder.
